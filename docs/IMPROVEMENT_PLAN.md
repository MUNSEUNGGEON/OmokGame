# 개선 계획

## P0 — 보안

| 작업 | 상태 | 난이도 |
|---|---|---|
| 비밀정보 환경 변수화 | 완료 | 중 |
| 기존 자격 증명 폐기·재발급 | 사용자 조치 필요 | 하 |
| 관리자 비밀번호 조회 제거 | 완료 | 하 |
| 평문 비밀번호 해시 마이그레이션 | 예정 | 상 |
| TLS 또는 HTTPS 통신 | 예정 | 상 |

## P1 — 신뢰성

- JUnit으로 4방향 5목, 모서리, 중복 좌표, 턴 위반, 종료 후 착수를 검증한다.
- 서버에 메시지 길이·필드·좌표·방·역할 검증기를 둔다.
- 승패 갱신과 회원/채팅 변경을 명시적 트랜잭션으로 처리한다.
- Flyway/Liquibase DDL을 추가해 새 환경을 재현 가능하게 만든다.

## P2 — 구조

- `core.Server`와 `core.Client`를 인증·대기실·게임·채팅 핸들러로 분리한다.
- 문자열 상수와 `//` 구분자 대신 enum과 JSON DTO를 사용한다.
- 중복된 `EmailUtil`과 `GameFrame` 후보를 하나로 통합한다.
- 장기적으로 `scr`을 `src/main/java`, 리소스를 `src/main/resources`로 이동한다.

## P3 — 운영

- GitHub Actions에서 Maven build/test와 secret scan을 실행한다.
- 구조화 로그, 접속 타임아웃, 속도 제한과 장애 지표를 추가한다.
- 게임·채팅 데이터 보존 및 삭제 정책을 문서화한다.
